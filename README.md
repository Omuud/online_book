## Student Semester Registration App

### Quickstart
- Create and activate a Python 3.11+ environment (optional)
- Install dependencies:
```bash
pip install -r requirements.txt
```
- Run the server:
```bash
python app.py
```
- Open `http://localhost:8000`

### Features
- Login via Student ID + Password
- Registration form (semester, program, year, courses, notes)
- Review & confirm summary step
- Dashboard with recent registrations
- Flash messages and Bootstrap UI
